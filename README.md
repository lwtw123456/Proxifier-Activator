# Proxifier-Activator

想要用来配合 Reqable 来进行抓包，就进行了分析。

最近在啃 Enigma Protector 7.X 的 Modern RISC VM，堪称吃屎，难度和工作量巨大，而这个程序本身没有保护，可以说是忙碌中的怡情了。

运行即完成，重新登录 Proxifier 即可。实测 v4.14，理论上所有版本都可以用。

代码都写完了才发现 2024 年就有人发表过分析文章，是针对 v4.12 的，还给出了 python 实现，与我的代码核心算法一致。

不过我的写法比文章中简洁高效的多，所以本仓库算是逆向练习了。

闲鱼上有人收费卖注册码，可以说是人心不古了，毫无互联网精神。
